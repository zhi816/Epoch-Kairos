2. **標題**：宋體大字
3. **示意圖**：寬度撐滿卡片內距，高度依 viewBox 比例

* 公式：論文頁的區塊公式（`$$...$$`）之一，逐字取用（見本檔第四節）。
* 示意圖：依 `diagram.md` 繪製，內容須對應論文頁 Card 3 所描述的機制。

## 三、標題（16 字內）

* 用白話說出「關鍵的一招」，最好是一個具體的動作或比喻：「把記憶變成能量的谷底」、「一道藍光，一個開關」。
* 比喻必須忠於機制：Hopfield 的記憶確實對應能量極小值，所以「谷底」可用；不得用原文沒有對應的比喻。
* 不得只寫方法名稱（「Hopfield 網路」、「Transformer 架構」）。

## 四、公式

1. **只能抄自論文頁**：取論文頁中最能代表核心機制的一條區塊公式；若該公式是 `aligned` 多行，只取其中一行。
2. **單行、夠短**：卡片寬 330px 時不得需要水平捲動。原始碼超過 70 字元時檢查腳本報 WARN，請改取另一條較短的公式，或只取 `aligned` 中最關鍵的一行。
3. **不得改寫公式**：不得簡化、改符號、省略下標、合併兩條公式。想簡化時，先依 `wiki-content-audit` 在論文頁加入有出處的簡化式，再從論文頁取用。
4. 化學式與離子用 `\mathrm{}`；公式內不得有中文（`AGENTS.md` 第三章）。
5. 論文頁完全沒有區塊公式時（例如綜述、語言學描述研究），**不得自編公式**。先回到論文頁：原文若有可定位的定義式、評估指標式或計算式，依 `wiki-content-audit` 補入論文頁並在證據表登記，再取用；原文確實沒有任何公式時，登記於 `wiki/todo.md`（範圍 `skill`）並告知使用者，等待決定，不得自行略過公式。

## 五、說明（40 字內）

* 白話解釋公式或機制「做了什麼」，而不是逐一翻譯符號。
* 若提到公式中的符號，同句必須說明它是什麼。
* 條件不可省略：Hopfield 的能量只降不升，前提是連接對稱，所以要寫「連接對稱時」。
* 好：「連接對稱時，每翻轉一個神經元，能量只降不升，網路必然停在某個谷底。」
* 壞：「E 是能量函數，T 是權重，V 是狀態。」（只翻譯符號）、「網路一定會收斂到正確記憶。」（比原文強：原文指出也會停在偽穩定態）

## 六、示意圖

每篇都必須有，規格與畫法見 [`diagram.md`](diagram.md)。在卡片檔中：

* 「圖類型」預設 `示意圖`。只有在畫的是原文真實的數據（曲線、長條、散點）時才寫 `數據圖`，並填「圖來源」（原文圖或表位置）。
* 「圖說」以 `示意：` 或 `數據：` 開頭，60 字內，用一句話說明圖在表達什麼，同時作為無障礙替代文字。
* 圖的標籤用詞要與標題、說明、論文頁一致。

## 七、範例（Hopfield）

```
- 標題：把記憶變成能量的谷底
- 公式：E = -\frac{1}{2} \sum_{i \neq j} T_{ij} V_i V_j + \sum_{i} U_i V_i
- 說明：連接對稱時，每翻轉一個神經元，能量只降不升，網路必然停在某個谷底。
- 圖類型：示意圖
- 圖說：示意：殘缺線索像一顆球沿能量地形滾下，深谷是記憶，淺谷是偽穩定態。
```

公式取自論文頁「全局李亞普諾夫能量泛函」一節（證據表：原文 p. 2556 式 (7)）；說明中的「連接對稱時」與「必然停在某個谷底」取自同節之 ΔE ≤ 0 推導；「偽穩定態」取自論文頁 Card 3 第 3 點。
