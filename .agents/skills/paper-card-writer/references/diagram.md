# Card 3 示意圖規範

每篇論文的 Card 3 都必須有一張示意圖（2026-11-09 使用者決定）。示意圖最容易出問題：畫成與內容無關的裝飾、畫出看似數據其實是編的曲線、標籤用詞與正文不一致、顏色寫死導致換卡組後看不見。本檔把每一個細節都定死，**不得自行發揮規格以外的畫法**。

## 一、原則

1. **圖要畫出 Card 3 講的機制**，讓讀者不看公式也能懂「關鍵的一招」。先寫圖說（一句話），再畫圖；畫完的圖必須正好表達這句話，不多也不少。
2. **示意圖不是數據圖**。不得有刻度、數值、單位、格線；曲線的高低、長條的長短只表示「多／少」「高／低」的相對關係，不得暗示原文沒有的量化結果。
3. **只畫原文有的東西**。原文是離體培養細胞就不要畫大腦；原文是模擬就不要畫實驗儀器；原文沒有的元件、步驟、箭頭方向一律不畫。
4. **簡單**：一張圖只講一件事。元素不超過 40 個、標籤不超過 6 個。
5. **顏色交給卡組**：圖中不得寫任何色碼，只能用本檔第五節的 class，由網頁依卡組（學科色底或深色卡）套色。

## 二、作業步驟

1. 寫圖說：`示意：……`，60 字內，說明圖中每個主要元素代表什麼。
2. 從第三節選一種圖型。都不適用時，以最接近者為基礎，不得混用超過兩種圖型。
3. 在 300 × H 的方格上先規劃位置（建議先在紙上或註解中列出每個元素的座標），H 介於 90 至 140。
4. 依第四至六節寫 SVG。
5. 依第九節逐項自我檢查，再跑 `check_cards.py`。
6. 能預覽時（論文頁建置腳本完成後），在 330px 與 500px 寬各看一次，確認標籤不重疊、不超出邊界。

## 三、圖型（擇一）

| 圖型 | 適用 | 畫法要點 | 例子 |
|---|---|---|---|
| A 地形／曲線 | 能量、損失、勢能等「往低處走」的機制 | 一條平滑曲線（`path` 的 C 指令），谷底以 `k-accent` 圓點標示，移動物以 `k-ink` 實心圓、移動方向以 `k-dash` 短線表示 | Hopfield 能量地形 |
| B 流程 | 依序處理的步驟、管線 | 2 至 4 個圓角方塊（`rect`，`rx="4"`）左到右排列，方塊之間用箭頭（第六節寫法），關鍵步驟的方塊加 `k-accent` | 拆詞綴 → 找詞根 → 翻譯 |
| C 前後對照 | 「以前這樣、這篇這樣」 | 左右兩半，中間一條 `k-muted` 豎線，左半用 `k-muted`，右半用 `k-line`／`k-accent`，上方各一個標籤 | 逐字讀句子 vs. 同時看整句 |
| D 結構分解 | 一個系統由哪些部件組成 | 外框 `rect` 用 `k-ink k-ring`，內部部件 `rect` 用 `k-soft`，關鍵部件用 `k-accent k-ring` | 干涉儀的兩條臂與雷射 |
| E 節點與連線 | 網路、注意力、關係 | 節點用 `circle`（r 3 至 5），連線用 `line`，強調的連線用 `k-line`，其餘用 `k-muted` | 每個字連到句中所有字 |
| F 空間示意 | 光、粒子、訊號在空間中的作用 | 只用幾何形狀（圓、矩形、直線、波浪線）表示對象，不畫寫實圖案 | 藍光照射細胞膜上的通道 |

## 四、畫布

```svg
<svg viewBox="0 0 300 124" role="img" aria-label="示意：殘缺線索像一顆球沿能量地形滾下，深谷是記憶，淺谷是偽穩定態。">
  ...
</svg>
```

* 根元素只能是 `<svg>`，屬性只能有 `viewBox`、`role`、`aria-label`。
* `viewBox` 固定為 `0 0 300 H`，H 為 90 至 140 的整數。不得寫 `width`、`height`、`xmlns` 以外的屬性（`xmlns` 可寫可不寫）。
* `role` 固定為 `img`；`aria-label` 與卡片檔「圖說」逐字相同。
* 所有座標落在 `0` 至 `300`、`0` 至 `H` 之內；文字基線與邊界至少留 4 單位，避免被裁切。
* 圖在卡片上會縮放到約 290px（手機）至 440px（桌面）寬，1 單位約 1 至 1.5px。線條間距小於 6 單位會黏在一起，請拉開。

## 五、元素、屬性與 class 白名單

### 可用元素

`g`、`path`、`line`、`polyline`、`polygon`、`circle`、`ellipse`、`rect`、`text`。其餘一律禁止，包括 `style`、`script`、`defs`、`linearGradient`、`marker`、`use`、`image`、`foreignObject`、`filter`、`clipPath`、`title`、`desc`、`tspan`。

### 可用屬性

| 元素 | 可用屬性 |
|---|---|
| 全部（`svg` 除外） | `class` |
| `g` | `class` |
| `path` | `d` |
| `line` | `x1`、`y1`、`x2`、`y2` |
| `polyline`、`polygon` | `points` |
| `circle` | `cx`、`cy`、`r` |
| `ellipse` | `cx`、`cy`、`rx`、`ry` |
| `rect` | `x`、`y`、`width`、`height`、`rx` |
| `text` | `x`、`y`、`text-anchor`（`start`、`middle`、`end`） |

**禁止**：`style`、`fill`、`stroke`、`stroke-width`、`stroke-dasharray`、`opacity`、`transform`、`font-size`、`font-family`、任何 `on*` 事件屬性、任何色碼或 `rgb()`。

### class（每個圖形元素必須至少有一個顏色 class）

| class | 意義 | 套色（卡組丁：學科色底） |
|---|---|---|
| `k-line` | 主角線條（主曲線、強調連線、關鍵框） | 學科深色重點色 |
| `k-accent` | 重點（谷底、關鍵節點、關鍵步驟） | 學科深色重點色 |
| `k-ink` | 中性物件（移動物、一般方塊、一般線） | 深墨色 `#0F1013` |
| `k-muted` | 次要物件（背景結構、對照組、偽狀態） | 深墨色約 55% 不透明 |
| `k-soft` | 淡色填滿區域（範圍、群組底色） | 學科深色重點色約 18% 不透明 |

修飾 class（可與顏色 class 並用，以空格分隔）：

| class | 作用 |
|---|---|
| `k-ring` | 封閉圖形（`circle`、`ellipse`、`rect`、`polygon`）只畫外框、不填色。未加時封閉圖形為實心填色 |
| `k-dash` | 虛線（軌跡、推論、尚未發生的步驟） |
| `k-thin` | 細線（輔助線、次要連線） |

* `path`、`line`、`polyline` 一律只畫線、不填色。
* 文字用 `k-label`（一般標籤，深墨色約 75%）或 `k-label-accent`（重點標籤，學科深色重點色）。`text` 不得使用其他 class。
* 我的關注論文之 Card 2 至 6 與群星相同，用學科色底（`DESIGN.md` 第五章第 2 節，2026-11-09 暫定），套色同上表；圖的寫法不分群星或我的關注，一律只用 class，套色由網頁處理。

## 六、常用畫法

**箭頭**（不得用 `marker`）：線段＋箭頭頭部兩筆，例如從 (100, 60) 指向 (140, 60)：

```svg
<line class="k-ink" x1="100" y1="60" x2="140" y2="60"/>
<polyline class="k-ink" points="134,55 140,60 134,65"/>
```

**圓角方塊加標籤**：

```svg
<rect class="k-ink k-ring" x="20" y="40" width="70" height="34" rx="4"/>
<text class="k-label" x="55" y="61" text-anchor="middle">找詞根</text>
```

**平滑曲線**：用 `path` 的 `M` 與 `C` 指令，控制點左右對稱可畫出谷底，例如 `M10 20 C 40 20, 50 90, 80 90 C 110 90, 120 30, 150 30`。

## 七、文字標籤

1. 最多 6 個 `text`，每個 8 字以內（字數計法見 `style.md`）。
2. 用詞必須出現在本卡標題、說明、圖說或論文頁中（檢查腳本會比對，找不到報 WARN）。
3. 示意圖的標籤不得含數字、單位或百分比；需要區分的同類物件用 `A`、`B` 或甲、乙。
4. 標籤放在所指物件的上方或下方，與物件相距 8 至 14 單位；標籤之間至少相隔一個字寬，不得重疊。
5. 字級由網頁統一控制，約等於 viewBox 的 11 單位，規劃位置時以每個中文字寬 11 單位估算。

## 八、數據圖（不建議，需要時才用）

只有當原文的某張圖或表正是機制的最佳說明時才使用：

* 「圖類型」填 `數據圖`，「圖來源」填原文圖表位置（例如 `Fig. 2`），「圖說」以 `數據：` 開頭。
* 畫出的每個數值都必須在證據表中可以找到；不得內插、外推或平滑出原文沒有的點。
* 軸以文字標籤標名稱，不畫刻度數字；數值寫在說明或 Card 4，不寫在圖上。
* 其餘規格（元素、class、標籤數）與示意圖相同。

## 九、自我檢查

- [ ] 先寫了圖說，圖正好表達圖說，沒有多畫也沒有少畫
- [ ] 選用第三節的一種圖型（至多混用兩種）
- [ ] viewBox 為 `0 0 300 H`（H 為 90 至 140），根元素只有 `viewBox`、`role`、`aria-label`，`aria-label` 與圖說逐字相同
- [ ] 只用白名單元素與屬性，沒有任何色碼、`style`、`stroke-width`、`transform`
- [ ] 每個圖形元素都有顏色 class，至少一個 `k-accent` 或 `k-line` 標出重點
- [ ] 元素 40 個內、標籤 6 個內、每個標籤 8 字內、示意圖標籤沒有數字
- [ ] 標籤用詞與標題、說明、論文頁一致
- [ ] 沒有畫原文沒有的東西；沒有刻度與數值；相對高低不暗示原文沒有的量化結果
- [ ] 所有座標在畫布內，標籤不重疊、離邊界至少 4 單位

## 十、完整範例（Hopfield，圖型 A）

```svg
<svg viewBox="0 0 300 124" role="img" aria-label="示意：殘缺線索像一顆球沿能量地形滾下，深谷是記憶，淺谷是偽穩定態。">
  <path class="k-line" d="M4 18 C 30 18, 40 96, 70 96 C 100 96, 106 40, 132 40 C 156 40, 160 70, 178 70 C 196 70, 204 30, 228 30 C 252 30, 258 104, 280 104 C 290 104, 294 60, 298 40"/>
  <circle class="k-accent" cx="70" cy="96" r="3.4"/>
  <circle class="k-accent" cx="280" cy="104" r="3.4"/>
  <circle class="k-muted k-ring" cx="178" cy="70" r="2.6"/>
  <circle class="k-ink" cx="22" cy="34" r="5"/>
  <line class="k-ink k-dash" x1="30" y1="42" x2="44" y2="66"/>
  <text class="k-label" x="34" y="20">殘缺線索</text>
  <text class="k-label-accent" x="70" y="116" text-anchor="middle">記憶 A</text>
  <text class="k-label" x="178" y="90" text-anchor="middle">偽穩定態</text>
  <text class="k-label-accent" x="280" y="120" text-anchor="end">記憶 B</text>
</svg>
```

對應：曲線＝能量地形（論文頁 Card 3「能量景觀」）；兩個深谷＝寫入的記憶；淺谷＝偽穩定態（論文頁 Card 3 第 3 點）；左上的球與虛線＝從殘缺線索出發、能量只降不升（論文頁 ΔE ≤ 0 推導）。

## 十一、反例

| 反例 | 問題 |
|---|---|
| 畫一顆發光的大腦與星星 | 裝飾，沒有畫出機制 |
| 曲線旁標「誤差 0.15」、軸上有刻度 | 示意圖不得有數值與刻度 |
| `<path stroke="#4D2E8B" .../>` | 寫死色碼，換卡組就錯色；必須用 class |
| 用 `marker` 畫箭頭 | 不在白名單，依第六節用 `polyline` 畫 |
| 標籤寫「Attractor」但正文寫「吸引子」 | 用詞不一致 |
| 離體細胞實驗卻畫出活體小鼠 | 畫了原文沒有的東西 |
