# 卡片文字檔格式（`wiki/cards/<slug>.md`）

每篇論文一個檔案，檔名與論文頁相同（`wiki/papers/1982-hopfield-network.md` 對應 `wiki/cards/1982-hopfield-network.md`）。建置腳本與檢查腳本逐行解析本檔，**格式錯一個符號就會解析失敗**，請逐字遵守。完整範例見 `wiki/cards/1982-hopfield-network.md`。

## 一、整體結構

檔案依序由下列部分組成，順序不得調換，不得增加其他標題或段落：

```markdown
# 卡片文字：<slug>

- **論文頁**：[<slug>](../papers/<slug>.md)
- **證據表**：[<slug>](../evidence/<slug>.md)
- **撰寫者**：<執行代理>（<模型版本>），YYYY-MM-DD
- **最後核對**：<執行代理>（<模型版本>），YYYY-MM-DD

## 封面
（欄位）

## Card 2｜世紀瓶頸
（欄位）

## Card 3｜突破原理
（欄位，最後接一個 svg 程式碼區塊）

## Card 4｜決定性數據
（欄位）

## Card 5｜典範轉移
（欄位）

## Card 6｜Kairos
（欄位）
```

* 第一行標題固定為 `# 卡片文字：` 加 slug，slug 須與檔名相同。
* 檔頭四行為固定的粗體標籤，連結一律為相對路徑。「撰寫者」記第一次建立本檔者；「最後核對」記最近一次依本 Skill 第五節完成全部步驟者，每次修訂都要更新。
* 六個區段標題逐字如上（全形直線 `｜`），不得改名、不得省略、不得調換順序。
* Card 1 沒有獨立區段：Card 1 由 Frontmatter 與「封面」區段組成（見 `cover.md`）。

## 二、欄位寫法

每個欄位一行，格式為：

```
- 欄位名稱：值
```

* 以 `- ` 開頭（半形減號加一個半形空格），欄位名稱後接**全形冒號** `：`，冒號後直接接值，不加空格。
* 值只能寫在同一行，不得換行，不得使用 Markdown 粗體、斜體、連結或行內程式碼。
* 一個值內有多個部分時，以**全形直線** `｜`（U+FF5C）分隔，前後不加空格。值本身不得再出現 `｜`。
* 可重複的欄位（如「對照」、「數字」、「里程碑」）每筆一行，重複寫欄位名稱，**依顯示順序排列**。
* 欄位之間可以有空行；不得有其他說明文字。需要給後續撰寫者的備註，寫在交付說明或日誌，不寫進本檔。
* 未列在各區段欄位表中的欄位名稱一律視為錯誤。

## 三、各區段欄位一覽

字數上限的計法見 `style.md` 第一節；各欄位的寫作要求見各卡細則。

### 封面

| 欄位 | 必填 | 次數 | 格式 | 上限 |
|---|---|---|---|---|
| 封面斷行 | 是 | 1 | 以全形斜線 `／` 分行之 `card_line` | 每行 9 字、最多 3 行 |
| 導語 | 是 | 1 | 一句或兩句白話 | 60 字 |
| 封面標題 | 否 | 0 或 1 | 取代自動擷取之短名 | 22 字 |
| 研究類型 | 我的關注且 `focus_languages` 為空時必填，其餘不得填 | 0 或 1 | 例如「綜述」、「文化復振」 | 6 字 |

### Card 2｜世紀瓶頸

| 欄位 | 必填 | 次數 | 格式 | 上限 |
|---|---|---|---|---|
| 標題 | 是 | 1 | 一句，可含一個全形逗號 | 16 字 |
| 對照 | 是 | 2 至 3 | `名稱｜說明` | 名稱 5 字、說明 30 字 |
| 缺口 | 是 | 1 | `名稱｜說明` | 名稱 5 字、說明 32 字 |
| 結語 | 是 | 1 | 一句，以全形句號結尾 | 22 字 |

### Card 3｜突破原理

| 欄位 | 必填 | 次數 | 格式 | 上限 |
|---|---|---|---|---|
| 標題 | 是 | 1 | 一句 | 16 字 |
| 公式 | 是 | 1 | LaTeX，不加 `$`；無公式模式填「無」（`card-03-secret.md` 第四節第 5 條） | 原始碼 70 字元（超過報 WARN） |
| 無公式理由 | 公式為「無」時必填，否則不得填 | 0 或 1 | 以「原文無公式：」或「原文僅有評估指標公式：」開頭，寫出如何確認 | 50 字 |
| 說明 | 是 | 1 | 一至兩句白話 | 40 字 |
| 圖類型 | 是 | 1 | `示意圖` 或 `數據圖` | |
| 圖來源 | 圖類型為數據圖時必填，否則不得填 | 0 或 1 | 第一手來源之圖或表位置 | 30 字 |
| 圖說 | 是 | 1 | 示意圖以 `示意：` 開頭；數據圖以 `數據：` 開頭 | 60 字 |

欄位之後緊接一個以 ` ```svg ` 開頭、` ``` ` 結尾的程式碼區塊，內含唯一一個 `<svg>`，規格見 `diagram.md`。

### Card 4｜決定性數據

| 欄位 | 必填 | 次數 | 格式 | 上限 |
|---|---|---|---|---|
| 模式 | 是 | 1 | `數字` 或 `結論` | |
| 數字 | 模式為數字時必填 | 2 或 4 | `值｜說明｜來源位置` | 值 7 字、說明 24 字、來源位置 40 字 |
| 結論 | 模式為結論時必填 | 2 或 3 | `內容｜來源位置` | 內容 26 字、來源位置 40 字 |
| 範圍 | 是 | 1 | 不含「範圍：」字樣 | 32 字 |

模式為數字時不得出現「結論」欄位，反之亦然。

### Card 5｜典範轉移

| 欄位 | 必填 | 次數 | 格式 | 上限 |
|---|---|---|---|---|
| 模式 | 否 | 0 或 1 | 只能填「新論文」；一般論文不填（`card-05-revolution.md` 第六節） | |
| 標題 | 是 | 1 | 一句 | 16 字 |
| 里程碑 | 是 | 3 至 5（新論文模式 2 至 4） | `年份｜內容｜出處`；出處為作者年份期刊、`獎項`，或 `本篇`（新論文模式須加原文位置，如 `本篇 §7`） | 年份 4 位數字、內容 22 字、出處 60 字 |
| 註記 | 是 | 1 | 說明哪些是後續他人成果；新論文模式須寫明出自本篇 | 24 字 |

### Card 6｜Kairos

| 欄位 | 必填 | 次數 | 格式 | 上限 |
|---|---|---|---|---|
| 結語 | 是 | 1 | 一至兩句 | 40 字 |
| 轉變 | 是 | 1 | `甲→乙`，箭頭為 `→`（U+2192），前後不加空格 | 甲、乙各 6 字 |

## 四、數學式與特殊符號

* **Card 3「公式」**：寫 LaTeX 原始碼，不加 `$` 或 `$$`，單行，不得含 `aligned`、`\\`、中文字元。必須逐字取自論文頁的區塊公式或其 `aligned` 中的一行（比對時忽略空白、`&`、`\,` 等間距指令）。化學元素與離子依 `AGENTS.md` 第三章使用 `\mathrm{}`。原文沒有表達本篇機制的公式時，依 `card-03-secret.md` 第四節第 5 條填「無」並寫「無公式理由」，網頁不放公式框。
* **行內數學**：只有 Card 3「說明」、Card 4「數字」的值與說明、Card 4「結論」可使用 `$...$` 行內數學（例如 `$0.15N$`、`$1/\sqrt{2}$`）。其他欄位一律寫純文字。行內數學內不得含中文。
* **不使用行內數學時**，可用 Unicode 符號書寫：`≈`、`≤`、`≥`、`×`、`−`（減號）、`√`、`σ`、`π`。不得用半形 `~` 表示約略。
* 金額依 `AGENTS.md` 第三章寫成「美元」，不得出現未轉義的 `$` 金額。

## 五、svg 程式碼區塊

```svg
<svg viewBox="0 0 300 124" role="img" aria-label="與圖說相同的文字">
  ...
</svg>
```

* 一個卡片檔只能有一個 svg 區塊，位置在 Card 3 區段的最後一個欄位之後、`## Card 4` 之前。
* 區塊內只能有一個 `<svg>` 根元素；元素、屬性、顏色與文字的全部限制見 `diagram.md`。

## 六、編碼與換行

* UTF-8（無 BOM），換行用 LF，檔案以一個換行結尾。
* 不得有 Tab 字元；不得有行尾空白。
