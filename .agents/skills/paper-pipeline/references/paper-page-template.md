# 論文頁骨架與逐欄寫法（S4）

本檔規範 SKILL.md 第五節 S4：`wiki/papers/<slug>.md` 怎麼寫。Frontmatter 欄位的基本規定以 `AGENTS.md` 第七章第 1 節為準，本檔把每一欄「怎麼決定、從哪裡來、常見錯誤」寫清楚，並給出正文骨架。正文怎麼依證據寫（限定語、歸屬、公式），依 `wiki-content-audit` 寫作模式第 3 步。網頁怎麼把這一頁轉成論文頁，見 `paper-card-writer` 之 `references/paper-page.md` 第二、五節；**本骨架的標題、引言、範圍說明與六段格式，都是建置腳本解析的依據，不得改動格式**。

## 一、骨架（複製後逐處替換 `<……>`，不得留下任何 `<`、`>` 佔位）

### 群星論文（`raw/` 根目錄之原始檔）

```markdown

title_zh: "<中文名>"
paper_year: <發表年>

timeline_year: <時間線年份；預設同 award_year>
authors: "<作者，依署名順序>"
laureates: "<得獎者；無獎項或得獎者即作者時，整行刪除>"
venue: "<期刊全名, 卷(期), 起-迄頁>"
honor: "<年份 獎項全名（表彰事由）；無獎項者整行刪除>"
domain: "<bio｜ai｜physics｜econ｜chem｜human 擇一>"
domain_tags: ["#<標籤>", "#<標籤>"]
concepts: ["<概念頁 slug>"]
status: "wiki"
verification: "unverified"
my_focus: false
doi_url: "https://doi.org/<DOI>"
key_papers:
  - "<作者> (<年份>) <標題>. <期刊> <卷>:<頁>. <網址>"
```

### 我的關注論文（`raw/my-focus/` 之下之原始檔）

與群星骨架相同，只有下列各處不同：

```markdown
award_year: <同 paper_year>
timeline_year: <同 paper_year>
（刪除 laureates、honor 兩行）
my_focus: true
focus_role: "<依 intake.md 第四節第 3 點之資料夾對照>"
focus_languages: ["<研究對象之低資源語言>"]
```

* 雙年份行寫 `**<paper_year> 發表 ｜ 個人核心研究關注**`。
* 學位論文之「本頁範圍」寫學校、系所、年月與指導教授；有會議版本時一併寫明（範例：`wiki/papers/2021-seediq-chinese-mt-you.md`）。
* `doi_url` 沒有時整行刪除，在「原始權威文獻」寫出原文連結或典藏處（例如國家圖書館臺灣博碩士論文知識加值系統）。
* Card 6 的個人研究映射，不得寫出使用者碩論的題目、資料或結果（`paper-card-writer` 第二節第 13 條）。

範例頁：群星看 `wiki/papers/2016-ligo-gravitational-waves.md`（2026-11-10 依本流程逐項核對）；我的關注看 `wiki/papers/2021-seediq-chinese-mt-you.md`。只看格式，內容不得套用。

## 二、Frontmatter 逐欄

| 欄位 | 必填 | 怎麼決定 | 常見錯誤 |
|---|---|---|---|
| `title` | 是 | 英文原題，照原文大小寫與標點；中文論文寫原文之英文題名（書名頁或摘要頁），沒有則依中文題名直譯並在交付說明寫明 | 改寫或縮短原題 |
| `title_zh` | 是 | 中文名。第一個全形冒號 `：` 之前的部分會成為卡片與星圖上的論文名，盡量在 16 字以內（超過 22 字時卡片檔須填「封面標題」）；冒號後可接副題。中文論文直接用原中文題名 | 冒號前寫成長句；加入原文沒有的評價（「劃時代的」） |
| `paper_year` | 是 | 實際發表年份，依 `intake.md` 第四節核對；與檔名前綴相同 | 用獲獎年份；憑 `raw/` 檔名推定 |
| `award_year` | 是 | 獲獎年；無獎項者同 `paper_year` | 無獎項卻留空 |
| `timeline_year` | 是 | 決定首頁時間線與 `wiki/index.md` 區段。預設同 `award_year`；與預設不同時在交付說明寫明理由 | 隨意填 |
| `authors` | 是 | 實際作者，依署名順序；合作組寫「<第一作者> et al. (<合作組名>)」 | 混入得獎者 |
| `laureates` | 有獎項才填 | 官方公告之得獎者全名 | 把作者照抄過來 |
| `venue` | 是 | 「期刊全名, 卷(期), 起-迄頁」；會議寫論文集全名與頁碼；學位論文與 arXiv 依 `intake.md` 第四節 | 混入獎項；縮寫期刊名 |
| `venue_short` | 選填 | **只在 S8 建置自我檢查報「資訊欄期刊名超過兩行」時**才填，依 `paper-card-writer` 之 `references/paper-page.md` 第三節 | 自創縮寫、中文意譯 |
| `honor` | 有獎項才填 | `"<年份> <獎項全名>（<表彰事由>）"`，全形括號；年份須等於 `award_year` | 加前綴、缺括號（網頁會顯示錯的獎名） |
| `domain` | 是 | 六值擇一，依本篇主要研究方法與貢獻所在；學科邊界依 `AGENTS.md` 第二章第 2 節 | 依主題字面歸類（語言學論文用了機器翻譯，主要貢獻是系統時歸 `ai`） |
| `domain_tags` | 是 | 一至四個，**只能取 `AGENTS.md` 第八章白名單**；跨學科者可加其他色系之標籤 | 自創標籤；使用已收斂之舊標籤 |
| `concepts` | 是 | 一至三個既有或新建之概念頁 slug，依 `concepts-and-index.md` 第一節 | 列了概念頁卻沒在概念頁 `papers` 反向登記 |
| `status` | 是 | 一律 `"wiki"`；`published` 只在 `web/papers/<slug>/index.html` 正式頁產出後使用（`wiki/todo.md` TD-002） | 建了原型就改 `published` |
| `verification` | 是 | 寫作時先填 `"unverified"`，S6 核對後依結果改為 `verified` 或 `partial` | 一寫完就標 `verified` |
| `my_focus` | 是 | 依 `intake.md` 第四節第 3 點 | 依主題判斷 |
| `focus_role` | 我的關注必填 | 依資料夾對照，五值擇一 | 依內容自行判斷 |
| `focus_languages` | 我的關注必填 | 研究所針對之低資源語言，以中文語言名書寫（`賽德克語`、`北薩米語`）；不列中文、英文等高資源或樞紐語言；同語族五種以上寫語族名（臺灣南島語寫 `臺灣南島諸語`）；綜述或不針對特定語言者填 `[]`（此時卡片檔須填「研究類型」） | 列入中文、英文；寫「原住民語」 |
| `doi_url` | 有 DOI 必填 | `https://doi.org/<DOI>`；arXiv 寫 arXiv 網址；學位論文無 DOI 者刪除此行 | 指向非本篇之版本 |
| `key_papers` | 獎項表彰多篇工作時必填 | 每筆一行：`<作者> (<年份>) <標題>. <期刊> <卷>:<頁>. <網址>`；建置腳本從第一個 `(年份)` 之前擷取作者姓氏 | 格式不一致，資訊欄顯示錯的姓氏 |
| `hook` | 是 | 一句話寫本篇做了什麼、得到什麼；不在網站顯示，只供撰寫卡片導語，但仍須忠於原文 | 誇大（「完美驗證」「全面超越」）；寫入原文沒有的比喻 |
| `card_line` | 是 | 首頁卡片一句話，規則見 `AGENTS.md` 第七章第 1 節與 `paper-card-writer` 之 `references/cover.md` 第二節：20 字以內、主詞是「這篇做了什麼」、無術語縮寫、無數字、最多兩個全形逗號；**寫完立刻試切封面斷行**（逗號在行尾、每行 9 字以內、最多 3 行），切不出來就改寫。強斷言（「第一次」）須在證據表有原文用語支持 | 切不成三行；照抄論文名；加評價詞 |

## 三、正文每一段要寫什麼

正文是論文頁網頁右側長文的全部內容，也是卡片唯一的文字來源（`paper-card-writer` 第二節第 2 條）。**卡片要用的東西，必須先寫在這裡**；這裡沒寫的，卡片不能寫。每一句事實都附原文位置（頁、節、表、圖），寫法依 `wiki-content-audit` 寫作模式第 3 步。

| 段落 | 必須寫到 | 供哪張卡使用 | 不得 |
|---|---|---|---|
| 標題下開頭引言 | 一句扣住本篇的話；Wiki 撰寫者在 `」` 後加「（本頁引言為 Wiki 撰寫，非原文）」 | 網頁長文 01 段首 | 寫成原文引文卻無出處；放數字而證據表沒有 |
| 本頁範圍說明 | 主軸論文、`key_papers` 與獎項之關係；學位論文寫學校、指導教授與會議版本 | 網頁資訊欄 | 刪除（需要時必寫） |
| Card 1 | 本篇在什麼背景下做了什麼、主要結果的質性描述；作者自己的定位（「首次」等）照原文用語並附頁碼 | 封面導語、Card 1 | 把後續成果或獎項寫成本篇結果 |
| Card 2 | 本篇之前的做法（**具名**：做法、工具或觀點的名稱）與各自的問題，至少兩個面向；還缺什麼。依作者在引言與相關研究中的說法，附頁碼 | Card 2 之對照列與缺口（名稱必須出現在這段） | 用常識補作者沒說的歷史；把使用者的研究寫進瓶頸 |
| Card 3 | 方法的步驟（條列）；原文公式以區塊公式寫出，每條附「原文式 (N)，p. X」，並在證據表登記；原文沒有公式者不放區塊公式，以文字說明關鍵的一招 | Card 3 之公式、說明、示意圖 | 自擬公式；把教科書公式當本篇公式；改寫原文公式之符號 |
| Card 4「本篇」 | 每個關鍵數字連同指標、資料集、方向、基線、條件與表列欄位；數字全部要在證據表 | Card 4 | 刪掉條件；四捨五入到與原文不同的精度；混入後續成果 |
| Card 4「後續」 | 後續研究：作者、年份、發表處、DOI，內容依該研究本身；沒有可寫者寫「（尚無可附出處之後續研究）」 | Card 5 之里程碑 | 無出處；誇大後續研究對本篇的承接 |
| Card 5 | 本篇帶來的改變。發表超過兩年者：至少 3 筆附出處之後續研究或獎項；發表兩年內者：本篇公開之資源、作者明列之限制、作者所述之未來工作，各附原文位置；原文沒有某項時寫「原文未提及」 | Card 5（一般模式或新論文模式） | 編造影響；把未來工作寫成他人成果 |
| Card 6 | 開頭寫「以下為 Wiki 詮釋：」，一至兩點具體到本篇的啟發，可附原文依據；我的關注論文可寫與使用者公開研究方向（概念頁名稱）之關聯 | Card 6 結語與轉變 | 換到任何一篇都成立的金句；透露碩論題目、資料或結果 |
| 知識網絡與文獻出處 | 概念頁連結、官方出處、**原始檔典藏路徑（`pipeline_status.py` 之 S1 依此檢查）**、證據表連結、獎項通告 | 網頁資訊欄、`pipeline_status.py` | 寫 `file:///` 本機路徑；漏寫原始檔典藏 |

格式要求（建置腳本與 `lint_wiki.py` 會檢查）：六段標題依序為 `## Card 1 ｜ 時代銘文 (The Hook)` 至 `## Card 6 ｜ 跨界思維與啟發 (The Kairos)`，可在中文名後加「：副標」；粗體成對；正文金額寫「美元」；化學離子用 `\mathrm{}`；長公式用 `aligned`；公式內不得有中文；全文不得有 Emoji 與驚嘆號。

## 四、寫完之後（S4 完成條件）

1. `python .agents/skills/wiki-content-audit/scripts/lint_wiki.py`：本頁無 ERROR；`card_line` 封面斷行之 WARN 須處理。概念頁相關之 ERROR（`concepts` 指向不存在的概念頁、雙向對應缺漏、指向 `../concepts/` 之連結失效）在 S5 新建或更新概念頁後消失，此時可先保留。
2. `python .agents/skills/paper-pipeline/scripts/pipeline_status.py <slug>`：S1、S3、S4 為 OK（S5 以後尚未做，NG 是正常的；概念頁相關之 ERROR 計入 S5）。
3. 未替換的佔位符由第 2 步之 S4 檢查（`<中文……>`、`<slug>`、`<DOI>`、`<URL>`）。不要用 `grep "<[^a-zA-Z/!]"` 自行搜尋：公式中的 `<`（如 `$\Gamma(0) < 2$`）也會被找出來。
